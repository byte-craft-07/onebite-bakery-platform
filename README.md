# 🍰 Bakery Platform

A modern, premium, mobile-first bakery ordering platform built with React, TypeScript, Node.js, Express and MongoDB.

## Vision

Provide the easiest bakery ordering experience while giving the owner complete control over products, orders and customers.

## Tech Stack

Frontend

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion

Backend

- Node.js
- Express
- TypeScript
- MongoDB
- Mongoose

## Features

- OTP Login
- Online Ordering
- Hybrid Cart
- Cake Customization
- Home Delivery
- Store Pickup
- COD
- UPI
- My Orders
- Order Tracking
- Order Again
- Favorites
- Reviews
- Invoice PDF
- Admin Dashboard
