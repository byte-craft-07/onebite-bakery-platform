# AGENT RULES

Never break existing functionality.

Always prefer reusable components.

Always think mobile first.

Never create duplicate code.

Never hardcode business values.

Everything configurable from Settings.

Always validate request data.

Always write clean folder structure.

Use proper HTTP status codes.

Keep controllers thin.

Business logic belongs in services.

Database logic belongs in repositories.

Optimize Mongo queries.

Never expose sensitive data.

Always consider future scalability.

Write readable code over clever code.
