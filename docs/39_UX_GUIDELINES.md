# 39 — UX Guidelines Specification

## 1. Core UX Principles
- **Frictionless Purchasing**: Customers can add items to cart as guest or logged-in user with 1 click.
- **Sensory Visuals**: Highlighting freshness, eggless preferences, weight options, and customization choices immediately on cards and detail pages.
- **Clarity in Delivery & Pickup**: Instant validation of home delivery eligibility and minimum thresholds (e.g. ₹300) before checkout.

---

## 2. Customer Journeys

### 2.1 Catalog & Quick Purchase Journey
`Landing Page` ➔ `Product Catalog / Filter` ➔ `Quick View / Detail Page` ➔ `Add to Cart Drawer` ➔ `Checkout` ➔ `OTP Login Modal (if guest)` ➔ `Payment` ➔ `Order Confirmation`.

### 2.2 Custom Cake Request Journey
`Home / Custom Cake Page` ➔ `Select Flavour / Weight / Tiers / Egg Preference` ➔ `Upload Reference Image` ➔ `Submit Request` ➔ `Track Request Status`.

### 2.3 Admin Operations Journey
`Admin Login` ➔ `Dashboard Metrics` ➔ `Order Queue` ➔ `Update Order Status (PENDING -> CONFIRMED -> PREPARING)` ➔ `Update Estimated Ready Time`.
