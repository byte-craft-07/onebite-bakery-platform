# 38 — Frontend Roadmap Specification

## Phase 1: Setup & Design System Foundation
- Initialize Vite + React 18 + TypeScript repository.
- Configure TailwindCSS design tokens, typography, and color tokens.
- Build core component library (Button, Input, Select, Modal, Toast, Drawer, Card).

## Phase 2: Customer Public Catalog & Discovery
- Build Home Page with Hero Banner, Featured Categories, Trending Products, and Occasions.
- Build Product Catalog Page with filters (Category, Occasion, Product Type, Price Range) and sorting.
- Build Product Detail Page with image gallery, customization selector, eggless option, and Quick Add.

## Phase 3: Hybrid Cart & Checkout Flow
- Implement Cart Drawer & Cart Page with real-time quantity adjustments.
- Implement Google sign-in and automatic guest-cart merging.
- Build Checkout Preview Page with home delivery vs store pickup selection and minimum delivery threshold warnings.
- Build Razorpay Payment gateway integration modal and signature verification feedback.

## Phase 4: Customer Account & Order Management
- Build Order History & Order Tracking Details Page with status timeline.
- Build User Profile and Address Management Page.
- Build Custom Cake Request Page with image reference uploads.

## Phase 5: Admin Management Dashboard
- Build Admin Product Management (Create, Edit, Pricing, Stock Status).
- Build Admin Order Management (Status transitions, ready time updates, cancellation handling).
- Build Admin Analytics & Platform Operations Dashboard (Metrics, Audit logs, Health status).
