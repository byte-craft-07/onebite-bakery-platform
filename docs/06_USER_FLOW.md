# MOBILE RULES

Every important action must be reachable with one thumb.

Maximum 3 taps to reach any primary feature.

No unnecessary screens.

Keep checkout on a single page.

Always show Cart.

Always show Search.

Always prioritize ordering over browsing.

---

# GOLDEN RULE

Customer should never feel confused.

If the customer has to think,
the design should be improved.
